Dockerfile

Dockerfile: el contenedor completo (código real del repositorio)

01

El reto

Una aplicación ligera para controlar la asistencia y gestionar fichas y personal, pensada para centros educativos o clínicas. Tenía que poder desplegarse en cualquier sitio con un par de comandos y con el frontend separado del backend.

02

Lo que hice

El frontend es una SPA en HTML, CSS y JavaScript sin frameworks: registro de personas y personal, control de asistencia, login con sesión, vistas por rol y búsqueda. Habla con la API por Fetch.

Lo empaqueté con la imagen oficial de Nginx: el Dockerfile copia el frontend al directorio web y arranca Nginx en primer plano. El backend, la API Node.js de Aupy en el puerto 3000, va aparte.

03

Stack y herramientas

Infra

  • Docker
  • Nginx

Frontend

  • HTML
  • CSS
  • JavaScript
  • Fetch API

Backend

  • API Node.js (Aupy)

04

Resultado y lo que aprendí

Se levanta con docker build y docker run -p 8080:80, y funciona contra la API de Aupy.

Lo que aprendí

Separar frontend y backend en contenedores distintos me deja desplegar y actualizar cada pieza por su cuenta.
